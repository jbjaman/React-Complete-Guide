JSX-এর পূর্ণরূপ JavaScript XML. এটি JavaScript-এর মধ্যে HTML-এর মতো syntax লেখার সুবিধা দেয়। JSX দেখতে HTML-এর মতো হলেও এটি HTML নয়।

const element = <h1>Hello World</h1>;

Rule 1: একটি Parent Element থাকতে হবে

function App() {
  return (
    <div>
      <h1>Hello</h1>
      <p>Welcome</p>
    </div>
  );
}

Rule 2: class নয়, className ব্যবহার করতে হয়

<div className="container">
  Hello
</div>

Rule 3: JavaScript expression লিখতে {} ব্যবহার হয়

const name = "Rahim";

function App() {
  return <h1>Hello {name}</h1>;
}

Rule 4: সব HTML tag properly close করতে হয়

<img src="image.jpg" alt="Profile" />
<input type="text" />
